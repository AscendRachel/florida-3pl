# Greentek Orders

A web app for the Florida 3PL warehouse (orders, scanning, returns, dashboard). Python 3 standard library only; no installs.

Run it on Windows by double-clicking `start.bat`, then open http://localhost:8765. The first visit asks you to create the admin account.

The `data/` folder (orders, returns, logins, uploads) is created on first run and is deliberately not part of this repository.
